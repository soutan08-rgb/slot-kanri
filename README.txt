パチスロ収支管理 PWA

GitHub Pagesで公開する方法
1. GitHubで新しいPublicリポジトリを作成します（例: slot-profit）。
2. このZIPを解凍し、slot-pwaフォルダ内の5ファイル（index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png）をリポジトリのルートにアップロードします。
3. リポジトリの Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save を選択します。
4. 表示された https://ユーザー名.github.io/slot-profit/ をiPhoneのSafariで開きます。
5. Safariの共有ボタン → ホーム画面に追加 を選択します。

注意: 記録はiPhoneのブラウザ内に保存されます。ブラウザデータの消去や端末変更に備え「データ」→「JSONバックアップ」を定期的に利用してください。GitHub Pagesで公開するとアプリのコードは公開されますが、端末内の収支記録がGitHubにアップロードされることはありません。
